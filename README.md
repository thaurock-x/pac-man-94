# **👾 Pac-Man 94**

Una versión moderna, ligera y completamente fluida del clásico Pac-Man, desarrollada en un único archivo HTML autocontenido (HTML, CSS y JavaScript nativo). Diseñada con una interfaz arcade futurista, adaptada tanto para computadoras como para dispositivos móviles.


## **✨ Características Principales:**

 * 🚀 Zero Dependencias: Todo el código (lógica, motor gráfico en Canvas, estilos y efectos de audio sintético mediante Web Audio API) se encuentra en un solo archivo .html ultraligero.
 * 📱 Diseño 100% Responsivo: Adaptado perfectamente para pantallas de escritorio y dispositivos táctiles (incluye controles en pantalla flotantes y soporte para gestos swipe).
 * 👻 Inteligencia Artificial de Fantasmas: Algoritmos de persecución y dispersión dinámicos, con soporte para estados de vulnerabilidad (superbolas/fright mode).
 * 🎵 Efectos de Sonido Retro: Generación de audio procedural en tiempo real sin archivos externos pesados.
 * 💾 Sistema de Récords (LocalStorage): Guarda automáticamente tu puntuación máxima localmente en el navegador.
 * ⚡ Optimización de Rendimiento: Bucle de juego independiente de los fotogramas (con interpolación de tiempo) para un movimiento suave en cualquier dispositivo.
## **🎮 Controles:**

-Computadora:
 * Movimiento: Flechas direccionales (↑, ↓, ←, ) o teclas W, A, S, D.
 * Pausa: Tecla ESPACIO.
 * Reiniciar: Tecla R.
   
-Dispositivos Móviles:
 * Utiliza los botones direccionales en pantalla o desliza el dedo (swipe) sobre el tablero de juego.

'''bash
   git clone https://github.com/tu-usuario/pacman-94.git
'''

## **🛠️ Tecnologías utilizadas:**
 * HTML5 Canvas: Para el renderizado gráfico de alta velocidad del laberinto, entidades y efectos de luz.
 * CSS3 Moderno: Variables CSS, gradientes radiales, sombras y diseño responsivo adaptativo con clamp().
 * JavaScript (ES6+): Programación orientada a componentes lógicos nativos y gestión de eventos de entrada múltiples (teclado, ratón y táctil).
